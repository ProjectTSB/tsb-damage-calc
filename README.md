# TSB ダメージ計算

Minecraft のデータパック [TheSkyBlessing](https://github.com/ProjectTSB/TheSkyBlessing)（TSB）の `api:damage` が 1 回のダメージをどう計算するかを、段階ごとの値で確かめる Windows 用のツールです。プレイヤーが Mob に与えるダメージと、Mob の攻撃でプレイヤーが受けるダメージの両方を計算できます。神器や Mob の数値を調整するときに、どの段でどれだけ減るかを手元で確かめるために使います。

ゲーム内と同じく、ダメージを 100 倍した整数で計算します。float への丸め、`data get` の切り捨て、scoreboard の割り算の丸めも、同じ順に再現しています。

![攻撃・防御の入力と、段ごとの計算結果が並んだ画面](docs/screenshot.png)

## 使い方

[Releases](https://github.com/ProjectTSB/tsb-damage-calc/releases) から `tsb-damage-calc.exe` をダウンロードし、ダブルクリックすると起動します。インストールは要りません。

1. 右上のボタンで計算モードを選びます。「上限 9999.9」は現在の TSB の計算、「上限 99999.9」はダメージの上限を 99999.9 に上げる TSB の [PR #1635](https://github.com/ProjectTSB/TheSkyBlessing/pull/1635) の計算です。
2. 上の帯で「与ダメージ」（プレイヤー → Mob）か「被ダメージ」（Mob → プレイヤー）、および難易度を選びます。攻撃元と対象は「攻撃」「防御」の列の右上でも切り替えられます。
3. 左の「攻撃」の列に攻撃の値と攻撃元の補正・バフを、中央の「防御」の列に対象の補正・バフと防具・耐性を入力します。
4. 右の列に段ごとのダメージと最終ダメージが表示されます。各段の「内部の整数」は、その段の後にゲーム内の scoreboard が持つ値です。入力を変えるとすぐ計算し直します。

### 入力項目

| 項目 | 内容 |
|---|---|
| Damage の型 | `30f` のように float で渡すか、double・int で渡すか。0.7f は 0.69 として計算されるなど、結果が変わることがある |
| 軽減エンチャント・エンチャント係数 | `api:damage` の引数 `ReduceEnchantment` と、その `modifier`。軽減エンチャントの合計 Lv に係数を掛けた値が EPF に足される。係数を空欄にすると、選んだエンチャントの既定の値（火炎耐性・爆発耐性・飛び道具耐性は 2、落下耐性は 3、その他は 1）を使う |
| 攻撃元の補正・対象の補正 | プレイヤーの `Attributes.Attack`・`Attributes.Defense` の基礎値（普通は 1）とバフ。バフを入れないなら、`api:modifier/<属性>/get` で取った値を基礎値に入れてもよい |
| 対象の耐性 | Mob の register の `Resist` とバフ。`1.4f` のように float で書いた値なら、「型」を float にする |
| 防具値・防具強度 | 対象の `generic.armor`・`generic.armor_toughness` の値 |
| 耐性エフェクトの Lv | amplifier + 1。0 は耐性なし |
| ダメージ軽減・軽減エンチャントの合計 Lv | 防具 4 部位のレベルの合計。軽減エンチャントの欄には攻撃で選んだエンチャントの分だけを入れる。欄の名前は選んだエンチャントの名前（火炎耐性など）になる |
| FixedDamage・Bypass | `api:damage` の同名の引数 |

### バフ

補正の欄の「＋ 装備のバフ」「＋ エフェクトのバフ」で、`api:modifier/<属性>/add` に渡すバフを 1 行ずつ足します。値は TSB のコードに書く `Amount` のまま入れます（+10% なら 0.1、-20% なら -0.2）。

装備とエフェクトでは、同じ値でも掛かり方が違います。

| 種類 | Operation | 掛かり方 | +0.10 と +0.15 を入れたとき |
|---|---|---|---|
| 装備（防具・神器） | `multiply_base` | 同じ補正先の分を全部足してから 1 回掛ける | ×1.25 |
| エフェクト | `multiply` | 1 つずつ順に掛ける | ×1.10 × 1.15 = ×1.265 |

エフェクトにも `multiply_base` を使うものがあるので、行ごとに掛け方（Operation）を変えられます。`add` は基礎値に足してから倍率を掛けます。

バフの行はゲーム内で付与される順に並べます。TSB はバフを足すたびに並び順を入れ替えるため、同じ補正先に 3 つ以上あると、エフェクトのバフが掛かる順が行の順と変わることがあります。このツールでもゲーム内と同じ順で掛けます。

欄の下には補正先ごとの組み立ての式と、ダメージ計算で使われる値（0.01 未満を切り捨てた値）が表示されます。Defense は TSB が値の符号を反転して積むので、値 0.2 で受けるダメージが ×0.80 になります。

### プリセット

「攻撃」「防御」の列の上にあるプリセットの欄で、それぞれの入力に名前を付けて保存し、あとで読み込めます。保存するときは「今の入力を保存」を開きます。

- 攻撃のプリセット：「攻撃の値」「固定ダメージ・Bypass」の欄と、攻撃元の補正・バフ
- 防御のプリセット：対象の種類、「防具・耐性」の欄と、対象の補正（Mob なら耐性）・バフ

「読み込む」は今の入力を入れ替え、「重ねる」はバフを後ろに足します。防御の「重ねる」は防具値・防具強度・エンチャントの Lv も足します。神器を 1 個ずつプリセットにしておき、装備する分を重ねると、違う神器を何個も装備した状態を作れます。同じ神器を複数持ったときの重ね掛けは計算しないので、そのときはバフの値に合計を入れます。

プリセットは `%APPDATA%\dev.tsb.damage-calc\presets.json` に保存されます。このファイルをコピーすれば、別の PC でも同じプリセットを使えます。

## 計算する範囲

`api:damage/modifier` から、`api:damage/` が体力を減らす量までを計算します。

1. 攻撃側の倍率（攻撃元がプレイヤーのとき）
2. 防具値・防具強度
3. 耐性エフェクト
4. エンチャント
5. 防御側の倍率（プレイヤーの Defense、または Mob の Resist）
6. 上限（計算モードに合わせて 9999.9 か 99999.9）
7. 難易度補正（対象がプレイヤーのとき）
8. 体力への反映（対象がプレイヤーのとき。`ScoreToHPFluc` に積む値で、double の誤差により 0.01 多く減ることがある）

「上限 99999.9」のモード（PR #1635）では、上限が難易度補正の後に掛かります。防具・耐性エフェクト・エンチャントの計算も、ダメージ 1000 以上で精度を落とさない計算に変わります。

次のものは計算しません。

- Mob の素の近接攻撃など、`api:damage` を通らない Vanilla のダメージ
- 緩衝体力の消費と、残りの体力
- Mob の体力を超えた分の切り捨て（最終ダメージは、体力で止める前の値）
- MP の回復、イベント、死亡メッセージ
- 装備を複数持ったときの重ね掛け（`MaxStack`・`StackReduction`）。バフの値には合計を入れる

計算の元にしたのは TheSkyBlessing の `95528d1b2` と、PR #1635 の `0ee4f16dc` です。それ以降に `api:damage` や `api:modifier` が変わると、結果がずれることがあります。

## 動作環境

Windows 10・11 で動きます。画面の表示に Microsoft Edge WebView2 を使います。WebView2 は Windows 11 と最近の Windows 10 に最初から入っています。

署名していない exe なので、ダウンロードした PC では初回起動時に SmartScreen の警告が出ることがあります。

## ビルド

必要なもの：Node.js 24 以上、pnpm、Rust（rustup）、Microsoft C++ Build Tools（「C++ によるデスクトップ開発」）。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm tauri build --no-bundle -- --locked
```

exe は `src-tauri/target/release/tsb-damage-calc.exe` に出力されます。Rust のバージョンは `rust-toolchain.toml` で固定しています。依存の追加・更新は公開から 7 日たったバージョンだけを使う設定（`pnpm-workspace.yaml`・`.cargo/config.toml`）にしています。
